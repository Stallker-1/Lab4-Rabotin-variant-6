### Анализ результатов эксперимента

В ходе лабораторной работы были сравнены сезонная наивная модель, наивная модель, ETS, ARIMA, Gradient Boosting, GRU и LSTM для прогнозирования временного ряда температуры. Для оценки качества использовались MAE, RMSE, MASE и Pinball loss при \(\tau=0{,}5\). Также измерялось время выполнения моделей.

Наилучшие результаты показала сезонная наивная модель: MAE = 1,0882, RMSE = 1,1755 и MASE = 1,9148. Время её выполнения составило около 0,0012 секунды. Второе место заняла модель Gradient Boosting с MAE = 1,4748 и RMSE = 1,7510.

Нейросетевые модели GRU и LSTM не превзошли простые методы прогнозирования. Значение MAE для GRU составило 2,0683, а для LSTM — 2,0843. При этом время выполнения GRU составило около 147,61 секунды, а LSTM — около 20,15 секунды. Это показывает, что в рамках данного эксперимента использование рекуррентных нейронных сетей не обеспечило повышения точности прогноза.

Наихудший результат показала модель ETS: MAE = 10,0176 и RMSE = 12,0787. Таким образом, эффективность методов существенно зависит от структуры временного ряда, его сезонности и особенностей выбранной модели.

По результатам эксперимента сезонная наивная модель является наиболее эффективной среди рассмотренных вариантов по значениям всех представленных метрик качества и времени выполнения. Однако данные эксперимента являются синтетическими, поэтому полученные выводы нельзя автоматически переносить на реальные измерения температуры. Для оценки применимости методов на практике необходимо провести дополнительную проверку на реальных данных датчика.

### Ограничения эксперимента

Основным ограничением является использование синтетического временного ряда температуры. Его закономерности могут отличаться от поведения реального датчика, включая шум, пропуски, резкие изменения и нерегулярную сезонность. Кроме того, приведённые метрики характеризуют качество моделей на выбранной тестовой выборке и не гарантируют аналогичных результатов на других временных интервалах.
